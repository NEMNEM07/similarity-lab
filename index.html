어떤 유사도가 수능 지문의 정답을 찾아낼까?

지문과 다섯 선지를 낱말 벡터로 바꾸고, 지문과 가장 비슷한 선지를 정답이라고 고르게 했다. 코사인 유사도, 자카드 유사도, 유클리드 거리 가운데 실제 정답을 가장 잘 맞히는 방법을 비교한다.

실제 수능 기출은 저작권 때문에 지문과 선지를 이 페이지에 싣지 않고 계산한 수치만 담았다. 원문은 파일을 불러와 이 브라우저 안에서만 볼 수 있다.

실험 자료
낱말 나누는 방식
벡터의 값
자카드 유사도는 낱말이 있는지 없는지만 보므로 이 설정을 바꿔도 값이 같다.

결과: 누가 정답을 더 많이 골랐나

점선은 다섯 선지에서 무작위로 찍었을 때의 기대 정답률 20%이다. 가장 높은 점수의 선지가 둘 이상이면 정답률을 나누어 계산했다.

설정을 바꿔 가며 비교

여섯 가지 설정에서 정답 선지를 고른 문항 수이다. 행마다 가장 높은 값을 표시했다.

문항별로 살펴보기

문항을 열면 지문과 선지별 점수가 나온다. 정답 선지는 초록색으로, 각 방법이 고른 선지는 굵게 표시된다.

기출 원문은 github 저장소에 있다. kice_items.json를 다운받아 넣으면 지문과 선지가 표시되고, 이 브라우저에 저장되어 다음에 열 때 자동으로 적용된다.

사용한 공식

벡터의 값 = 단어 빈도수　또는　단어 빈도수 × 역 빈도수
역 빈도수 = ln( 전체 문서 수 N ÷ 문서 빈도수 )
코사인 유사도 = (A · B) ÷ (|A| |B|)　　클수록 비슷
자카드 유사도 = |A ∩ B| ÷ |A ∪ B|　　클수록 비슷
유클리드 거리 = √( Σ (aᵢ − bᵢ)² )　　작을수록 비슷
|A − B|² = |A|² + |B|² − 2 (A · B)
